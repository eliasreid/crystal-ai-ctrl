# crystal-ai-ctrl

WIP

Plugin for BizHawk's GBHawk emulator for control the opponent trainer's actions.

Interfaces with this webserver and browser client (https://github.com/eliasreid/pokemon-enemy-ctrl-web) to allow remote control of enemy trainers.

## Setup

Run `downloadEmulator.sh` from project root directory to download and extract compatible version of the emulator to the correct location.

See BizHawk ext tools wiki for instructions on how to build and run an external tool: https://github.com/TASVideos/BizHawk-ExternalTools/wiki

Run the emulator with the external tool and a compatible ROM, then click the `Connect` button to start a session. See https://github.com/eliasreid/pokemon-enemy-ctrl-web repo for instructions on setting up the server.
